# v1 audit 2026-09-16

Head-developer audit of the working tree between 0.1.3 and v1, with two
read-only code audits (coordination layer, memory primitive) and live
measurements against the running 0.1.3 daemon. ADR-0013 is the v1
definition; every finding below is a task on the Tirith board.

## Measurements on this repository's own daemon
- [measurement] tools/list is 10.5 KB for 17 tools; notice_publish alone is 1.1 KB of schema #tokens
- [measurement] task_list 66 KB, decision_list 34 KB, contract_list 30 KB, notice_list 12 KB with default arguments #tokens
- [measurement] every tool result is sent twice, once as structuredContent and once as the same JSON in the text block #tokens
- [measurement] the working tree does not compile mid-edit; storage-claude reported the persistence rework green at 02:00Z before the memory glue started #build

## Coordination findings
- [blocker] one bad line in notices.jsonl or decisions.jsonl, or one bad contract file, makes load fail and the daemon refuse to start; task 85cc7844 #storage
- [blocker] the stdio shim checks neither daemon version nor repo root, so an install does not upgrade anyone and a stale daemon.json can point at another repo's daemon; task 2e31aea6 #shim
- [major] a persist failure is logged and the tool still answers ok; no fsync before rename; meta.json written before data; task 6f41fed4 #storage
- [major] leases are reaped silently and every call renews every lease; ADR-0015, task 44ee9c43 #claims
- [major] any agent can take or close another agent's in_progress task, and orphaned tasks block their dependency subtree forever; task 401ed7c9 #tasks
- [major] republishing a contract without consumers wipes them and the notice reaches nobody; no expected_version; task 5ed3595f #contracts
- [major] notice_ack rewrites all of notices.jsonl; acks and brief delivery markers must be append-only; noted on task 87e14abd #notices
- [major] the dashboard clones the whole state under the lock every 2 s per browser; task 6037c840 #dashboard
- [minor] Page::newest_first skips rows sharing the cursor timestamp; told storage-claude #paging

## Memory findings
- [blocker] one unparseable note aborts load; unquoted list items let a newline in a tag write an unloadable file; loader ignores path/permalink mismatch; task ff6b9d5b #memory
- [major] no memory_delete and last-writer-wins updates; task d4f23a0a #memory
- [major] memory_search returns full bodies, context() clones bodies uncapped, scoring counts substrings, permalinks collide past 120 chars and fail on non-ASCII titles; task 6137f8af #memory
- [fact] the domain module has no panics in non-test code and no lock held across an await #memory

## Benchmark, live tree as built 02:30Z (details in docs/3-tests/01-testing-strategy.md)
- [measurement] 1 agent 132 calls/s (0.1.3: 76); reads 0.3-0.8 ms; every mutation waits ~17 ms for the flush #storage
- [measurement] 100 agents 733 calls/s, claim p50 48 ms; 1000 agents 936 calls/s, claim p50 77 ms but p95 3.4 s; zero errors at every size #storage
- [measurement] memory_write p50 25 ms / 314 ms / 3.4 s at 1 / 100 / 1000 agents because each note file is fsynced serially; task fc218faa #memory
- [measurement] memory_search p50 0.6 ms / 263 ms / 1.0 s at 1 / 100 / 1000 agents: scoring under the State lock is the slowest read under load #memory
- [measurement] bytes per agent per round 27 KB at 1 agent, 186 KB (~46k tokens) at 1000, driven by claims_list (97 KB) and status (54 KB) growing with live agents #tokens
