# Tirith project status

- Tirith: Rust MCP coordination server for parallel coding agents (claims, task board, contracts, change notices, decisions log). Not a memory layer.
- Stack: Rust edition 2024, rmcp 3.4 (server + reqwest client + stdio transport), axum 0.8, single daemon per repo over streamable HTTP at 127.0.0.1:7477/mcp with a dashboard at `/` and a liveness probe at `/api/health`. In-memory `State` written through to JSON under `.tirith/` by a sequence-ordered `Persister`. ADRs in `docs/5-decisions/`.
- 0.1.x pre-alpha built 2026-09-15: all 17 tools exist (`claim`, `release`, `renew`, `claims_list`, `task_*`, `contract_*`, `notice_*`, `decision_*`, `status`), CLI with one subcommand per tool (`src/cli.rs`, binary only), `examples/demo.sh` passes, clippy/doc/machete/deny clean. Released as `tirith-mcp` on crates.io (binary `tirith`), prebuilt archives via cargo-dist.
- `tirith stdio` (`src/stdio.rs`, ADR-0006) is the per-session shim clients spawn: finds or starts the daemon, proxies `tools/list` and `tools/call`. See memory `workflow/stdio-shim`.
- Layout: `src/server.rs` (tool inputs + outcome JSON + `start`), `src/state.rs` (lock, reap, touch, snapshots), `src/store.rs` (JsonStore + Persister + daemon.json), `src/dashboard.rs` + `dashboard.html`, `src/client.rs` (MCP client with NeverRetry transport), `src/stdio.rs` (shim), domain modules one per primitive, `src/types.rs` (AgentId, RepoPath, ids). Integration tests: `tests/http_roundtrip.rs`, `tests/stdio_shim.rs`.
- Conventions that bite: every tool outcome is `{status: ok|conflict|not_found|none|invalid, ...}` and never an MCP error; any call by an agent renews its leases; `RepoPath` strips trailing `/` and overlap is ancestor-at-segment-boundary; `pub(crate)` default with `unreachable_pub` on; tests may `unwrap` via crate-level cfg_attr.
- Binding rules: `AGENTS.md` and `docs/4-style/01-rust-rules.md`. Tool schemas authoritative in `docs/1-about/04-primitives.md`.
- Tirith is registered in `.mcp.json` and `.cursor/mcp.json` as `command: tirith, args: [stdio]`; the shim starts the daemon, nothing to run by hand. The installed `tirith` on PATH must have the `stdio` subcommand (`cargo install --path .` after pulling). Basic Memory notes in `.memory/`.
- Next: agent-facing hardening from real multi-agent use, contract shape validation, notices linked to claims.
