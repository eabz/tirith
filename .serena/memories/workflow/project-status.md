# Tirith project status (updated 2026-09-16 04:10Z by the head-developer session)

- Tirith: Rust MCP coordination server for parallel coding agents. Six primitives: claims (leases), task board, contracts, change notices, decisions log, memory notes scoped to repository paths (ADR-0011), plus runtime-only agent messages (ADR-0020). Not a general-purpose memory server.
- v1 is defined by ADR-0013 (`docs/5-decisions/0013-v1-definition.md`); ADRs 0010 to 0021 all landed on 2026-09-16. Board at 04:10Z: every code task closed except the notice seen-log wiring (66f16442, head-dev-fable with claude-ci-speedup); open besides it are the release checklist (task 9252b03e, for eabz) and the per-area production review tasks (`FOR agent-N ONLY`).
- Tool surface: 22 tools. There is no notice_ack: a notice is seen when delivered (brief on claim or an unread listing), decision 3f6d77d9 / ADR-0021; seen marks live in `.tirith/runtime/notice_seen.jsonl`. `claim` returns a brief (notices, contracts, decisions, memory excerpts, `more` counts, 4 KB cap) and `lost` / `previous_owner` per ADR-0015; every result may carry `lost` and an `inbox` of messages. Lists are paged newest-first with a `before` cursor and compact rows; status/claims_list/renew return the caller's view by default. tools/list about 7.7 KB (budget test 7,800 in tests/budgets.rs).
- Storage: per-primitive deltas and one coalescing Persister (ADR-0010), tolerant load with load_errors, durability tiers (only runtime state is fsynced). Benchmarks in `docs/3-tests/01-testing-strategy.md`; at 100 agents every tool is about 45 ms p50 after the fsync tiers and the Arc<MemoryBook> copy-on-write search.
- Menu bar tray on macOS only (`tirith tray`, cargo feature `tray`, ADR-0019); Windows tray is out of scope (decision 9f574339). Daemons register in `~/Library/Application Support/tirith/daemons.json`.
- Rules that bite: every tool outcome is status JSON, never an MCP error; cross-file input types need a constructor (NewMemory::new + with_*), never a struct literal in another file (decisions 1a7acfb0, 19c6595c); a pub type change must keep the tree compiling; run `scripts/check.sh` (one line per step) instead of reading full test output, targeted `cargo test --lib <module>` while editing, the full chain once before releasing claims.
- Registration: `.mcp.json` and `.cursor/mcp.json` run `tirith stdio`; the shim starts, replaces (ADR-0016) or refuses (other repo) the daemon. After `cargo install --path . --locked --force` the next session's shim replaces the daemon; only a same-version dev build needs the manual restart in memory `workflow/daemon-restart`.
- Memory routing: path-scoped knowledge is a Tirith memory note in `.tirith/memory/`; short navigation facts are Serena memories. Basic Memory is retired (ADR-0012).
- Post-v1 ideas recorded in conversation, not on the board: a one-page agent brief instead of reading all docs at session start (largest token saving), folding contract_get/task_pull/renew into their list/update/claim tools, smaller default limits, shorter row keys.
