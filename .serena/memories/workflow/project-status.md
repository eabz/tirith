# Tirith project status (updated 2026-09-16 by the head-developer session)

- Tirith: Rust MCP coordination server for parallel coding agents with five durable primitives: claims (leases), task board, contracts, change notices, decisions log, and memory notes scoped to repository paths (ADR-0011). Not a general-purpose memory server: no conversation history, no embeddings.
- v1 is defined by ADR-0013 (`docs/5-decisions/0013-v1-definition.md`): coordination layer, memory layer, and per-surface token budgets, each guarded by a test. Every bullet maps to a Tirith task id. ADRs 0010 to 0018 all landed on 2026-09-16 (incremental persistence, memory primitive, Basic Memory retired, v1 definition, brief on claim, lease loss and max age, shim replaces stale daemon, tool result and schema budget, task ownership and contract republish).
- Stack: Rust edition 2024, rmcp 3.4, axum 0.8, one daemon per repo over session-based streamable HTTP at 127.0.0.1:7477/mcp (decision 48538341: sessions stay; scripts use the CLI), dashboard at `/` served from a cached view with ETag, `/api/health` reports version, root and load_errors.
- Tool surface: 20 tools (17 original plus memory_write/read/search; memory_delete is coming), tools/list about 6.6 KB, every result's text block is a one-line status under 200 bytes, lists are paged newest-first with a `before` cursor and compact rows, status/claims_list/renew return the caller's own view by default (`all: true` / `verbose: true` for the full board). `claim` returns memory note excerpts for the claimed paths and, once brief lands, unread notices, contracts and decisions too.
- Storage: per-primitive deltas, one coalescing background Persister (ADR-0010), tolerant load with load_errors, durability tiers (decision d9f6673a: fsync runtime state only). Benchmarks in `docs/3-tests/01-testing-strategy.md` "Reference numbers": 1 agent 132 calls/s, 100 agents 2,375 calls/s after the fsync tiers, 1000 agents 936 calls/s, zero errors.
- Leases (ADR-0015, `src/claims.rs`): activity renews only up to 4 TTLs (max 4 h) from claimed_at; `claim` and `renew` restart it; directory claims absorb held children; reaped leases are remembered in `Reaped` so the next response carries `lost` (wiring per contract "Lost lease reporting").
- Rules that bite: every tool outcome is status JSON, never an MCP error; cross-file input types need a constructor, never a struct literal in another file (decisions 1a7acfb0, 19c6595c); a change to a pub type must keep the tree compiling; integration tests in `tests/` need their own `#![allow(clippy::unwrap_used, clippy::expect_used)]`.
- Registration: `.mcp.json` and `.cursor/mcp.json` run `tirith stdio`; the shim starts the daemon and, since ADR-0016, replaces one of another version or refuses one of another repo. After `cargo install --path . --locked --force`, restart the daemon per memory `workflow/daemon-restart`.
- Memory routing: if you can name the repo files the knowledge is about, it is a Tirith memory note in `.tirith/memory/`; short navigation facts are Serena memories. Basic Memory is retired (ADR-0012).
- Open after 2026-09-16 (see the board): agent-messages primitive (task 392e40bb, ADR-0019), consolidated budgets test file and CI additions (2b2d63d9), acks out of notice rows (66f16442), v1 release checklist (9252b03e: version bump, prune malformed decisions, rerun benchmarks, tag 1.0.0).
