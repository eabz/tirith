Claim the symbols you edit, not whole files. Each entry in `paths` is an anchor `<file>#<Symbol>` naming a top-level function, class, or module-level constant, such as `app/router.py#build_pipeline` or `app/config.py#Config`, or a member such as `app/config.py#Config.from_env`. Claim the anchor of every symbol you change, including callers you update. A new symbol or member is claimed by its new name (`app/config.py#MY_TABLE`, `app/config.py#Config.my_field`); import lines and `__all__` entries you need ride on your symbol claim in that file. Claim a whole file only for a new file (such as a new module or your test file) and for a file where you only change imports or `__all__` entries (such as `app/middlewares/__init__.py`). A file claim overlaps every anchor in that file, while different symbols of the same file can be held by different agents at once, so another agent may write to the file while you work: re-read the file right before you write, change it by replacing only the lines of your symbols (never rewrite a whole shared file from an earlier copy), and leave it importable after every write. If a check fails inside a symbol someone else holds, message that agent instead of fixing their symbol.
